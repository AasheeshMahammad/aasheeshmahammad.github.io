# aasheeshmahammad.github.io

Personal portfolio site of **Aasheesh Mahammad**, a software engineer. Live at **https://aasheeshmahammad.github.io**

- Plain HTML, CSS and JS with no build step, served by GitHub Pages
- Dark/light theme toggle, smooth scroll-reveal animations, mobile friendly
- The projects section loads public repositories live from the GitHub API

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Customize

- Text (about, roles, skills) lives in `index.html`; the typing roles are in `script.js`
- Colors are CSS variables at the top of `style.css`
